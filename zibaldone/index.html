zibaldone / knowledge base
Zibaldone (Italian, 1800s): a personal notebook where writers and scholars collected thoughts, quotations, reflections and fragments of knowledge. Giacomo Leopardi's Zibaldone di pensieri (1817–1832) is the most famous example: 4,500+ pages of accumulated insight.

Intentional, not automatic

No chat logging. You (or your agent) decide what deserves long-term memory.

Retrievable when it matters

Find notes even when you don't remember the exact words.

Continuity across sessions

Today's solution is available to tomorrow's conversation, in any MCP client.

Features

Save the value, not the noise

One Node.js process serves the MCP endpoint and a web app for everyday browsing and curation. Changes made by your agent show up instantly in the UI, and vice versa.

Publish from any chat

Your assistant stores structured entries: title, summary, Markdown content, category, tags and the original question.

Hybrid semantic search

Full-text BM25 and local embeddings fused with RRF, then diversified with MMR. No external AI service needed.

Vaults, categories & tags

Markdown-first entries

Read entries rendered with headings, lists and code blocks; edit them in place or create new ones by hand.

Safe delete with a bin

Deleted entries go to the bin for 30 days. Restore or purge them one by one or in bulk.

Import / Export JSON

Versioned, portable JSON backups. Move your knowledge between machines or storage backends.

OAuth 2.1 & API keys

Web assistants connect via OAuth with PKCE; local agents and IDEs use personal API keys. Every user sees only their own entries.

    How search works

    Lexical precision meets semantic recall

    Exact identifiers and paraphrases both find their way back. Embeddings are computed locally with Transformers.js (MiniLM, 384 dimensions).

    Full-text pass

    FTS5 / tsvector with BM25 ranking for exact terms.

    Semantic pass

    Cosine similarity over local embeddings or pgvector.

    RRF fusion

    Reciprocal Rank Fusion (k=60) merges both lists.

    MMR diversity

    λ=0.7 avoids near-duplicate results.

    Graceful fallback

    LIKE / text-only search if needed: always an answer.

    Connect

    Up and running in minutes

    Point the assistant you already use to https://zibaldone.organizer.solutions/mcp and sign in.

    OAuth 2.1 — automatic
    1. Add a custom connector / remote MCP server in your assistant's settings.
    2. Paste your server's /mcp URL.
    3. Sign in and approve the consent screen: the assistant registers itself (dynamic client registration + PKCE). No API key to copy.
    https://zibaldone.organizer.solutions/mcp
    API key — manual
    1. Create a personal API key from your profile in the web app.
    2. Add the server to your client's MCP configuration (e.g. ~/.cursor/mcp.json).
    3. Reload the MCP servers: the tools appear in your agent.
    {
  "mcpServers": {
    "zibaldone": {
      "url": "https://zibaldone.organizer.solutions/mcp",
      "headers": { "X-API-Key": "zib_YOUR_API_KEY_HERE" }
    }
  }
}
