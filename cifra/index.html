The right 2FA code, for the site you're on.

Cifra is a zero-knowledge TOTP authenticator that lives in your browser. Open it on a sign-in page and the code for that site is already at the top: one click copies it.

Features

Less hunting for codes, more signing in

Everything you expect from an authenticator app, built around the tab you are looking at.

Codes for the active tab

Exact host or *.domain matching; the account you used last on that site goes first.

Add from the page

On a site's 2FA setup page, one click reads the QR code from the visible tab. Or type the secret by hand.

One-click copy

Click a code to copy it. The clipboard is cleared 30 seconds later, only if it still holds that code.

Bring your codes

Import from Google Authenticator, Aegis, 2FAS or otpauth:// lists. Export to an encrypted backup.

Auto-lock

The vault locks after a period of inactivity (15 minutes by default) and when the browser closes.

A well-protected account

Sign-up confirmed by an emailed code, a 24-word recovery key you must prove you saved, optional 2FA with an authenticator app, passkeys or backup codes, and sign-in with Google.

Offline-first

Changes are saved encrypted on the device and uploaded as soon as the server is reachable.

Self-hostable

Use the hosted service or point the extension to your own Cifra server from the sign-in screen.

Security

Your master password never leaves the browser

Every key that can decrypt your secrets is derived on your device. The server stores ciphertext and a hash of an authentication key, nothing it could use to generate a code.

Argon2id

Your master password becomes a master key (64 MiB, 3 passes), on your device.

HKDF-SHA256

Separate keys for signing in and for unwrapping the random vault key.

AES-256-GCM

Each secret is encrypted with the vault key, bound to its item id.

Server

Receives only ciphertext and the auth key, which it hashes again with Argon2id.

What the server stores

  • Your email address
  • Encrypted secrets and the wrapped vault key
  • Service names and linked domains, in clear text so the badge works while locked
  • Sessions and a security log for your account

What it never sees

  • Your master password or the keys derived from it
  • Your TOTP secrets or the codes they generate
  • The pages you visit: tab URLs are matched locally
  • Analytics, trackers or ads: there are none
