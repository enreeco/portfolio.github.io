01 · Getting started

Install, create a profile, find your way

NEXUS is a desktop app: no account, no sign-in, no server. Your tasks live in a database file on your computer, and the app opens straight onto them.

Install

Download the installer for your system from the download section. The installers carry everything they need — you do not need Node.js or anything else.

SystemInstallerThe nexus command
Windows.exe — no administrator rights neededAdded to your PATH by the installer (open a new terminal)
macOS.dmg — drag NEXUS to ApplicationsSettings → CLI & Agents → Command line → Install nexus command
Linux.deb for Debian / Ubuntu, or the AppImageInstalled with the .deb; not available with the AppImage
The installers are not code-signed yet, so your system asks before the first launch. Windows: More info → Run anyway. macOS: right-click NEXUS in Applications → Open. Linux: make the AppImage executable (chmod +x).

Your first profile

  1. The app opens with no profile. Click the profile switcher at the top right → Create Profile.
  2. Give it a name — Work, Home, a client — and create it. The database file is created for you, on your computer.
  3. Click New Task and start writing. Or bring in what you already have: Settings → Data → Export & import → Import JSON.
  4. Optional, but recommended: choose a backup folder in Settings → Profiles → Backups (chapter 11).

The window at a glance

Header

Search, the profile switcher, New Task, ↻ to reload, and ⚙ Settings. Settings opens as a tab of its own, beside Tasks.

Sidebar

The Views button switches between the pages of the app; under it, the filters of the view you are on.

View bar

← / → walk back and forth through the views you visited; + opens the current view in a new tab; then Favorites, Presets, Group and the view's own tools.

Tabs

Under Tasks, a strip of task tabs appears as soon as you open one: a project, a preset, a search, a filtered view.

Next: Tasks and the task sheet
02 · Tasks

Tasks and the task sheet

Every task opens in the same sheet, whether you are reading it, editing it or creating it: a header, the description and its tabs in the middle, the properties on the right.

What a task holds

  • Title and description — the description is Markdown, and links in it open in your browser.
  • Project and section, a due date (with Today, Tomorrow and Next week buttons), status, priority, area and activity type.
  • Tags, people (picked from your contacts) and your own custom fields (chapter 9).
  • Notes: comments signed with your name, which you can edit and delete.
  • Relations to other tasks — blocks, depends on, related — as a list or a graph.
  • Files & links: attach files to the task, and keep links to the resources it needs.

Each task gets a short code such as TASK-00042. A child task shows its parents at the top of the sheet, with their status, so you always know where it belongs.

Edit in place

You rarely need an edit form. In the sheet, click a property to change it in a small popup, click the title or the description to rewrite them, add a file or a relation straight from its tab. Each change is saved at once, and a message offers Undo.

  • The status menu and the Complete / Reopen button sit in the header.
  • Copy link gives a nexus:// link that opens the task again from anywhere.
  • ⋯ → Duplicate copies a task into a new one; ⋯ → Delete removes it.
  • Long pick lists filter as you type: start typing a value, press Enter to pick it.

New tasks start in the right place

New Task fills in what the view you are on already says: if you are looking at one project's tasks with status To do, the new task starts in that project, as To do, and shows up right where you created it. In a grouped list, each group has its own + New Task, and in the Calendar each day has a + that sets the due date. Tick Create another to save and start the next task in the same project and section.

In the sheet: E edits, Ctrl/⌘+Enter saves the form, Esc closes the innermost thing open, and 1–9 pick a value in an open menu. If you close a form with unsaved changes, NEXUS asks first.

03 · Views

One work, many views

The same tasks, looked at the way the moment needs. Pick a view from the sidebar's Views button; the filters follow you between the task views.

ViewWhat it is for
DashboardTotals, a monthly timeline and charts by any field — plus your own widgets (chapter 4).

The Calendar in detail

  • Overdue is always relative to today, in red, with how many days late each task is.
  • Within a day, tasks are ordered by priority, as your priority list orders them.
  • The Calendar item in the Views list carries a red badge: how many open tasks are overdue or due today.
  • Days a routine falls on carry a ↻ icon; today's open routines are listed among today's tasks, outlined in green.

Completed tasks

The Task List and the Kanban hide completed tasks, so they show what is left to do. Turn on Show completed in the toolbar to see them, or filter by a completed status. The Dashboard always counts them.

Next: Dashboard and widgets
04 · Dashboard

Dashboard and widgets

Where you stand, in one page: totals, a timeline by month and charts by status, priority and area — all following the filters of the sidebar.

Build your own widgets

The Widget Builder makes the chart you need, and Add Widget puts it on the dashboard:

  • Group by any filterable field, or by month.
  • Stack by a second field — e.g. tasks per project, stacked by status.
  • Count tasks, or sum / average a number or currency field — a budget per area, hours per month.
  • Give a widget fixed filters, so it always shows the same slice of your work.
Which fields the builder offers is up to you: it uses the fields marked filterable in Settings → Fields → Field properties (chapter 9).
Next: Filters, tabs and favorites
05 · Finding things

Filters, tabs and favorites

Narrow the work down to what matters now, keep several slices open side by side, and come back to them in one click.

Filters

The sidebar has a filter for each filterable field: status, priority, area, project, section, tags, people, custom fields and more — you choose which, and in which order. Tick values to keep only those tasks, or use NOT to leave them out. The active filters show as chips above the tasks.

Group sorts the Task List and the Kanban into groups by any field, and remembers the groups you folded away.

Presets

Save a combination of filters — and a sort, ascending or descending — as a preset, and apply it again later. A preset can also open in a new tab.

Task tabs

Work on several things at once without losing your filters. A tab opens from:

  • the + next to the view's title — the current view with its filters;
  • a project's, section's or contact's task count, in Projects and Contacts;
  • a preset's New tab, or a favorite;
  • the search box: results get a tab of their own, which follows as you type and closes when you clear it. Search looks in task codes, titles, descriptions, tags, people and text fields.

Each tab keeps its own view, filters, grouping and sort, and its own history: ← / → (or Alt+← / →, or your mouse's back and forward buttons) walk through the views it showed. The main tab keeps your usual filters untouched.

Favorites

The ☆ Favorites menu saves the page you are on under a name — the view, plus its filters, grouping and sort — and opens it again in the same tab or in a new one. Rename and delete them from the same menu.

Next: Many tasks at once
06 · Bulk edits

Many tasks at once

Moving ten tasks to another project, or giving a whole group a new due date, takes one form, not ten.

  1. In the Task List, tick the tasks you want. The header checkbox selects every task shown; a group's checkbox selects that group only.
  2. Open Actions → Edit Selected…. The task sheet opens with the selected tasks listed in the middle (× leaves one out) and the fields they share on the right.
  3. Each field shows the value the tasks have in common, or Mixed — keep when they differ. Change only what you want to change; the rest stays as each task has it.
  4. The eraser beside a field empties it on every task. For tags and people, a value you add is added to every task, one you remove is removed from all.
  5. Apply lists the changes for you to confirm, then saves them all in one go.
A bulk edit that would leave a required field empty is refused, so your rules hold for every task. Delete Selected, in the same menu, removes the selected tasks.
Next: The desk
07 · Desktop

The desk

A view like no list: your projects lie as folders on a desk. Open one, take out the tasks you are working on, stick a note beside them — the way you would on a real desk.

Pan and zoom

Drag the desk around, zoom with the wheel or the buttons. The closer you zoom, the more each task shows.

Folders

One per project. Open a folder and it becomes a sheet with one column per section.

Tasks on the desk

Drag a task out to focus on it, or find one with Add a task. Send it back with ↩, or drop it on its folder.

Sticky notes

Notes in a colour from the palette, and one font for all of them: handwriting, sans serif, serif or monospace.

Which projects

Projects puts folders on the desk or away — all, none, or only the ones you filter — and Tidy up arranges them.

Routines board

Show your open routines on the desk, and tick their steps right there.

Saved desks

Give a desk a name and it saves itself as you go — its title shows when it was last saved. Keep several desks (This week, Q4 launch) and switch between them from Saved desks; New desk starts a fresh one. Ctrl/⌘+Z and Ctrl/⌘+Y undo and redo your changes. Hide completed, on by default, keeps finished tasks out of the way.

Next: Routines
08 · Routines

Routines: checklists that come back

The things you do again and again — a morning recap, a weekly report, the monthly invoices — written once, and back on the day they are due.

Schedules

A routine comes back every day, every working day (Monday to Friday), every weekend day, on the days of the week you choose, every week, or on a day of the month every N months. Give it a start and, if you like, an end date.

How an occurrence works

  • Each time the routine comes round, NEXUS creates an occurrence: a task with one step per item of the checklist, due on its day (a weekly one, on the Sunday of its week).
  • Tick the steps as you go; the occurrence shows its percentage, and ticking the last step completes it.
  • An occurrence stays open until you complete or archive it. Left open past its day, it shows as overdue in the Calendar.
  • Each occurrence keeps its comments, and the routine keeps the history of every occurrence.
  • A step can carry fields of its own — another project, a higher priority — on top of those the routine gives every task.

Pause, change, end

Create and edit routines in the task sheet, like a task, with a routine block for the schedule and the steps. A change applies to the occurrences still to come. Pause a routine for the holidays — nothing is created until you resume it — or End it when it has served its purpose.

Where routines show

  • Routines view: the open occurrences as cards, then every routine with its history.
  • Calendar: a ↻ icon on the days a routine falls on — future days as a preview — and today's open routines among today's tasks.
  • Desktop: the routines board, with steps you can tick.
Routines stay out of the task lists, the Kanban and the dashboard, so your project work is not buried under daily checklists.
Next: Fields you shape
09 · Fields

Fields you shape

NEXUS adapts to how you work, not the other way round. Every profile has its own projects, values, fields and rules.

Projects and sections

In the Projects view, create projects with an icon and a colour, and split each into sections — Discovery, Build, Launch. A task belongs to one project and, optionally, one of its sections.

Your own values

Settings → Fields → Standard fields holds the values of status, priority, area, activity type and resource type. Rename them, add your own, reorder them, and give each an icon and a colour. A status can be flagged as completed, so NEXUS knows which tasks are done.

Custom fields

Settings → Fields → Custom fields adds the fields your work needs, shown under Additional details in the task sheet:

TypeExample
Text, MarkdownA ticket number; acceptance criteria
Number, currencyEstimated hours; a budget in EUR
Single or multiple choiceChannel: Web, Email, Event
CheckboxApproved
Date, date and timeKick-off; a meeting slot

Contacts

The People of a task are contacts — name, company, email, role — picked with a type-ahead in the task sheet, or created there on the fly. Manage them in the Contacts view, with a default company for new ones.

Filterable and required

Settings → Fields → Field properties decides two things for every field:

  • Filterable: the field gets a filter in the sidebar — in the order you set — and becomes available to the Widget Builder and to grouping.
  • Required: a task cannot be saved without it, in the app as from the command line.
Next: Profiles
10 · Profiles

Profiles: one database each

Keep work and home apart, or give each client their own space. Every profile is a separate database, with its own tasks and its own setup.

Switch profiles from the switcher at the top right; the app reloads onto the other database in a moment. Manage them in Settings → Profiles: rename, pick an icon, remove.

Start from…

A new profile does not have to start from scratch:

Start fromThe new profile gets
Default configurationThe built-in values, no custom fields
The active profile's configurationIts values, custom fields, settings and projects — no tasks
A configuration file…A setup exported earlier, from this computer or another
A copy of a database file…A full copy of another NEXUS database — tasks, projects, contacts and setup

Settings → Profiles → Configuration exports a profile's setup — values, custom fields, settings, dashboard widgets, presets and, if you like, projects — to share it, or to keep two profiles aligned.

Next: Your data and backups
11 · Your data

Your data, and backups that are safe to sync

Your tasks are a SQLite file on your computer — not on our servers, because there are none. NEXUS makes backups of that file the safe way.

Local first

Each profile's database sits in the app's data folder, on your disk. No account, no telemetry, nothing leaves your computer unless you send it somewhere.

Do not put the live database in Dropbox, OneDrive or iCloud. Sync clients can damage a database that is open. Let NEXUS publish snapshots there instead — written once, never changed, exactly what sync clients handle well.

Backups to a folder

Settings → Profiles → Backups → Local backup:

  • Folder — any folder, a cloud folder included.
  • Every (minutes) — how often to take a snapshot; one more is taken when you quit. Nothing is published when nothing changed.
  • Keep per device — how many snapshots to keep from each computer.
  • Back up now, and the list of snapshots with Restore.

Backups to Google Drive

In the Google Drive sub-tab, Connect signs in to Google in your browser, and the profile's snapshots go to a folder of its own on your Drive — no Drive app needed, alongside the folder above or instead of it. NEXUS sees only the files it created there, nothing else in your Drive. Restore or download a snapshot from the same panel; Disconnect leaves the files where they are.

Two computers, one profile

When another computer has published a newer snapshot — in the folder or on Drive — NEXUS asks at startup: load the backup, or keep the current version (which then becomes the newest one for the other computer).

Restoring is reversible

Before a restore replaces your data, NEXUS publishes the current state as a snapshot. Changed your mind? Restore that one.

Export everything

Settings → Data → Export & import writes the whole profile — tasks, comments, relations and attached files — to one JSON file, and imports it back. No lock-in.

Next: Command line and AI agents
12 · CLI & AI

The command line, and AI agents

The nexus command ships with the app and works on the same databases. Anything you do in one shows up in the other — the open app refreshes itself when the command line writes.

What it does

Tasks, comments, relations, attachments, projects, contacts, fields, routines, desks, favorites, profiles, backups, export and import: every change you can make in the app, you can make from the terminal. Output is a readable table, or JSON with --json.

# what is in progress, as JSON
$ nexus task list --status "In Progress" --json

# a new task in a project, due Friday
$ nexus task add --title "Draft the Q4 objectives" \
    --project "Q4 planning" --priority High --due 2026-10-30

# one change, many tasks
$ nexus task bulk-update TASK-00012 TASK-00013 --status Done

# the routines still to do today
$ nexus routine instances --open

# a snapshot into your backup folder, now
$ nexus snapshot create
  • A task can be named by its code (TASK-00042) or by a piece of its title.
  • --profile <name> runs one command on another profile, without switching.
  • nexus <group> <command> --help lists every option.

Let an AI agent work with your tasks

NEXUS comes with agent skills that teach an AI agent — Claude Code, the Claude Agent SDK and others — to drive the nexus command: find and update tasks, plan your week from your real work, set up a profile, take care of backups.

nexus-tasks

Find, create, update and complete tasks; comments, relations, attachments, routines.

nexus-setup

Profiles, projects, values, custom and required fields, contacts, configurations.

nexus-backup

Snapshots, full export and import, moving to another computer.

Get them

Settings → CLI & Agents → Agent skills → Download skills (.zip): always the skills of your version.

The agent works on your computer, through the same command you would type: your data still goes nowhere NEXUS did not already keep it. The app and the command line can be used at the same time.
